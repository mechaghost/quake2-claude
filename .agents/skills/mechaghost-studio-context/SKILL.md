# MECHAGHOST studio context and media

Follow this repository's AGENTS.md and the current task first. Use this skill when a decision affects another project, when reporting a release, or when a capture demonstrates a meaningful milestone.

## Read the studio context

Use the private studio briefing and media intake references supplied by Elbert or the coordinating assistant. Do not expose those references or any private workspace content in this repository.

Read only the relevant project rows and recent source-linked changes. Treat the studio briefing as orientation, not permission to change another repository or evidence that a change shipped. Verify the project's current source, exact tested build or commit, CI, deployment, or store availability separately as appropriate. Use only already-authorized accounts and tools; if the private Pages are not available, continue the repo work and state the coverage gap. Never copy private studio content into public issues, PRs, files, or posts.

## Hand back one useful update

For a meaningful milestone, report: project, what changed, status (source, tested build, deployed, or store-live), source link, and any blocker or lesson another project can reuse. Do not report every commit or reopen paused work.

## Curate one capture

Use existing canonical media if it captures the result. Otherwise, select one 10–30 second clip or up to three stills per milestone. Aim for a clip under 20 MB and stay within the upload tool's limit. Label the project, date, build or commit, platform/device, what it demonstrates, and whether it is cleared for external sharing or internal-only.

Use the authorized private Media Library intake if available and within the task's scope; verify the resulting reference and avoid duplicate uploads. If you cannot access it, hand the coordinating assistant the canonical link or transferable artifact plus the same labels. No raw capture dumps, private tester faces, customer content, credentials, or public posting. Do not change sharing permissions or use the skill as authority to upload otherwise restricted material.
